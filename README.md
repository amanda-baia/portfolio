## 📌 Sobre o projeto

Landing page profissional e responsiva, desenvolvida como portfólio pessoal durante o curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

O site reúne minha trajetória no Direito e na tecnologia, meus projetos e um formulário de contato. Ele foi construído aos poucos, ao longo das atividades da disciplina: começou em HTML semântico, ganhou estilo com CSS3, interatividade com JavaScript e, por fim, layout responsivo com **Bootstrap 5**.

## ✨ Funcionalidades

- **Capa em tela cheia** com fundo de constelação (inspirado na minha identidade visual) e apresentação em português e inglês
- **Navbar responsiva** que fica transparente sobre a capa e muda de cor ao rolar a página
- **Tema claro e escuro**, usando o modo escuro nativo do Bootstrap 5.3 (`data-bs-theme`)
- **Prévia dos projetos ao passar o mouse**, com transição suave
- **Formulário de contato** com validação do Bootstrap, contador de caracteres e mensagem de confirmação
- **Rascunho automático**: o que é digitado no formulário fica salvo, mesmo se a página for fechada
- **Registro da última visita** exibido no rodapé
- **Layout responsivo** para celular, tablet e computador
- **Cores acessíveis**, com contraste conferido nos dois temas

## 🛠️ Tecnologias e conceitos aplicados

| Tecnologia | Onde foi usada |
|---|---|
| **HTML5** | Estrutura semântica (`header`, `nav`, `main`, `section`, `article`, `footer`) |
| **CSS3** | Variáveis, degradês, `flexbox`, `transition`, `@keyframes`, `clamp()`, `@media` |
| **Bootstrap 5** | Container, Grid System, Breakpoints, Navbar, Cards, Formulários, Badges e Classes Utilitárias |
| **JavaScript** | Manipulação do DOM, eventos, `localStorage`, `sessionStorage` e `cookies` |
| **SVG** | Logo e fundo de constelação, nítidos em qualquer tamanho de tela |

### Onde cada dado fica salvo

| Recurso | O que guarda | Por quanto tempo |
|---|---|---|
| `localStorage` | Rascunho do formulário de contato | Até ser apagado |
| `sessionStorage` | Tema escolhido (claro ou escuro) | Enquanto a aba estiver aberta |
| `cookie` | Data da última visita | 30 dias |

## 🚀 Como rodar no seu computador

1. Baixe ou clone este repositório:
   ```bash
   git clone https://github.com/amanda-baia/portfolio.git
   ```
2. Abra a pasta no **VS Code**.
3. Clique com o botão direito no `index.html` e escolha **Open with Live Server**. Também dá para abrir o arquivo direto no navegador.

> É preciso estar conectado à internet para carregar o Bootstrap e as fontes do Google Fonts.
